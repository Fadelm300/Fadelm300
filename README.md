## Featured Projects

### InsightBoard CRM

A private, single-admin CRM for managing clients, deals, projects, revenue, and expenses in one application.

- **Business workflows:** client and deal management, deal-to-project conversion, and project tracking.
- **Financial overview:** revenue and expense management, dashboards, and charts with BHD currency.
- **Access protection:** authentication, protected routes, and soft deletion.
- **Interface:** Arabic/English support and light/dark themes.

**Built with:** Next.js, TypeScript, Node.js APIs, MongoDB/Mongoose, MUI, Tailwind CSS, and Recharts.
